# maniskill_place_sphere_clean_40ep

RGB replay trajectories: 40 episodes, 10,720 action steps.

`trajectory.h5` contains the full observations, actions, and simulator states. `trajectory.json` contains environment settings and episode metadata. HDF5 trajectory IDs and episode order are preserved from the source RGB replay file. No external source files are required.

This is ManiSkill HDF5 source data, not an exported LeRobot dataset. See the parent README for download and inspection instructions. Data files are preserved byte-for-byte; no new license is assigned by this upload.
