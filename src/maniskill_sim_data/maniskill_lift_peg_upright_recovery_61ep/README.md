# maniskill_lift_peg_upright_recovery_61ep

Raw simulator trajectories and traces: 61 episodes, 22,642 action steps.

Each `seed_*/` directory retains `trajectory.h5`, `trajectory.json`, `trace.npz`, and `manifest.json`. This is the full pre-mixture source pool, not the smaller RGB-replayed selection used for the mixed dataset. These raw trajectories do not include RGB observations.

This is ManiSkill HDF5 source data, not an exported LeRobot dataset. See the parent README for download and inspection instructions. Data files are preserved byte-for-byte; no new license is assigned by this upload.
